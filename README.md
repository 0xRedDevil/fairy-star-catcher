# Fairy Star Catcher 🧚✨

A little browser game: guide the fairy to catch stars and hearts while dodging stormy clouds.

- ⭐ Star: +1
- 💖 Heart: +3 and an extra life (up to 5)
- ☁️ Cloud: lose a life

Top 5 scores are saved in the browser (localStorage).

## Play

No build step. Open `index.html` in any browser, on desktop or a tablet/phone. Drag (or tap) to move the fairy.
